execution waves. Music, menus, radio dialogue, multiple stages and touch stay out.

## Decisions

- 2026-11-05 (João): "add all core mechanics" — this PRD.
- 2026-11-05 (agent): Somersault = hold climb + press boost; U-turn = hold climb + press brake. The source arms with a
  forward-then-back stick motion. That is awkward on keys, so the arming window is dropped.
- 2026-11-05 (agent): Wingmen are unnamed allies with no dialogue; help calls show as a HUD marker, not radio text.
